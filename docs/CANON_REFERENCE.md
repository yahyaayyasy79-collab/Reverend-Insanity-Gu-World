# Canon reference — Reverend Insanity (蛊真人) for the Gu World mod

A session's starting point for lore work. It holds **no text from the novel**, its translations, the manhua or fan
art (MOD_SPEC §2 rule 6): only facts the mod relies on, in our own words, each with the source a research pass
checked. The novel is © Gu Zhen Ren; this is an index, not a substitute.

Compiled 2026-11-04 from the verdicts recorded in `docs/LORE_MAPPING.md`, `docs/GU_RESEARCH.md`, `docs/PATHS.md`,
`docs/CANON_OVERHAUL.md` and `data/*.csv`. **If this file and those disagree, they win**: they are where each verdict
was first recorded, and the CSVs drive the ruleset.

## How to use it

* **Before lore work, read this file, then the section of LORE_MAPPING.md it points to.** CLAUDE.md asks that every
  lore claim, the user's or ours, be checked against the raw text before it enters the plan. A claim already listed
  here with a source does not need a new search.
* **Citations.**
  * `R V5/14` or `R V5c14` is the raw Chinese text, volume 5, chapter 14.
  * `R ch597` is a global chapter number (2,335 chapters). Global = volume chapter + 199 (V2), +404 (V3), +648 (V4),
    +1020 (V5), +1965 (V6), about ±2.
  * `F Page_Name` is the fan wiki page; `W` is the wiki without a page name. The wiki has known errors (below), so a
    wiki-only claim stays [VERIFY].
* **Verdicts.** CANON (the text says it), ADAPTED (canon bent for the game, the bend stated), INVENTED (the text
  names nothing; ours), [VERIFY] (not yet checked; the user decides, MOD_SPEC_2 Boundaries).
* **New research.** The user allowed source research by subagents ("riset sumber semuanya", 2026-10-18). Research
  notes do not survive the container: record each new verdict in LORE_MAPPING.md (and here, if it is a core fact).
* **The novel itself.** Never commit it or paste passages into the repository. If the user holds a copy, they can
  upload it at the start of a session (it lives only in that container).

### Venerables

Ten, by era: Remote Antiquity, Primordial Origin and Star Constellation; Olden, Limitless, Reckless Savage and Red
Lotus; Medieval, Genesis Lotus, Thieving Heaven and Giant Sun; Late, Spectral Soul and Paradise Earth (R V6/119,
V5/302, V5/628). Primordial Origin's path is qi (he also founded enslavement) and Paradise Earth's is earth: both
R-checked corrections of MOD_SPEC's seeds. The other paths come from the seed list: Star Constellation wisdom, Genesis
Lotus wood, Giant Sun luck, Thieving Heaven theft, Red Lotus time, Spectral Soul soul, Reckless Savage strength,
Limitless rule. Lines that support some of them: Red Lotus's vital Gu is Spring Autumn Cicada, time path (R V5/456);
Thieving Heaven's true inheritances are theft-path (R V4/300, V4/341); Reckless Savage's are strength and
transformation (R V3/192, V4/63). Star Constellation, Genesis Lotus, Spectral Soul and Limitless are not each
checked here: [VERIFY]. A Venerable is unbeatable in its era (R V6/105); while one lives, Heaven's Will thins the
world's Lifespan Gu (R V5/54).
